# Лабораторна робота №2

## Тема
Клас із кількома конструкторами. Життєвий цикл об’єкта.

## Мета роботи
Навчитися використовувати перевантажені конструктори, виклик одного конструктора з іншого за допомогою `: this()`, а також ознайомитися з життєвим циклом об’єкта та роботою збирача сміття.

## Варіант 2 — Car

### Реалізований клас
Клас `Car` містить:

- приватне поле `_brand`;
- приватне поле `_model`;
- приватне поле `_year`;
- публічні властивості `Brand`, `Model`, `Year`;
- перевірку року — він не може бути в майбутньому;
- конструктор без параметрів;
- параметризований конструктор;
- виклик конструктора через `: this()`;
- метод `StartEngine()`;
- фіналізатор (деструктор).

### Конструктори

Конструктор без параметрів створює автомобіль із такими значеннями:

```text
Brand = Unknown
Model = Unknown
Year = 2000

Параметризований конструктор дозволяє задати марку, модель та рік автомобіля.

Створення об'єктів

У програмі створено три автомобілі:

Car car1 = new Car();
Car car2 = new Car("BMW", "M5", 2022);
Car car3 = new Car("Toyota", "Camry", 2023);

Для кожного автомобіля викликається метод:

StartEngine();
Збір сміття

Для демонстрації роботи життєвого циклу об'єктів використано:

GC.Collect();
GC.WaitForPendingFinalizers();

Після того як об'єкти стають недоступними, збирач сміття може викликати їхні фіналізатори.
