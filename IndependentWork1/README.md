# Самостійна робота №1

Тема: базовий синтаксис C# і оголошення класів.

Реалізовано три власні класи: `Game`, `CoffeeOrder`, `Bicycle`. У кожному є приватні поля, властивості, конструктор і метод з логікою. У `Main` створюються об'єкти та демонструється робота методів.

## Запуск
```bash
dotnet run
```
