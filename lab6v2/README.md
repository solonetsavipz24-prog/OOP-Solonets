# Лабораторна робота №6

## Тема
Наслідування. Ключові слова `base`, `override`, `virtual`. Приховування членів (`new`).

## Мета
Навчитися створювати ієрархії класів, використовувати `base`, `virtual`, `override` для реалізації поліморфізму та розуміти різницю між `override` і приховуванням членів за допомогою `new`.

## Варіант 2
Реалізована ієрархія:

- `Shape` — базовий клас: `Color`, `virtual double GetArea()`, `GetShapeType()`;
- `Circle` — похідний клас: `Radius`, `override GetArea()`, власний метод `Draw()`;
- `Rectangle` — похідний клас: `Width`, `Height`, `override GetArea()`, власний метод `Draw()`;
- у `Rectangle` метод `GetShapeType()` приховує однойменний метод базового класу за допомогою `new`.

## Що продемонстровано

1. Виклик конструктора базового класу через `base(...)`.
2. Перевизначення методу `GetArea()` через `override`.
3. Поліморфна поведінка під час виклику `GetArea()` через посилання типу `Shape`.
4. Різниця між `override` і `new`.
5. Власні методи похідних класів `Draw()`.

## Контрольні запитання

### 1. Що таке наслідування в ООП?
Наслідування — це механізм, за якого похідний клас отримує властивості й методи базового класу та може додавати або змінювати поведінку. Наприклад, `Circle` і `Rectangle` є різновидами `Shape`.

### 2. Для чого використовується `base`?
`base` дає доступ до членів базового класу. У цій роботі `base(color)` викликає конструктор `Shape` з конструктора `Circle` або `Rectangle`.

### 3. У чому різниця між `virtual` та `override`?
`virtual` у базовому класі дозволяє перевизначити метод у похідному класі. `override` задає нову реалізацію цього методу. Завдяки цьому під час виклику через посилання базового типу виконується метод реального типу об'єкта.

### 4. Для чого використовується `new`?
`new` приховує член базового класу, але не перевизначає його. Тому результат залежить від типу посилання: для `Rectangle` викликається `Rectangle.GetShapeType()`, а для посилання `Shape` — `Shape.GetShapeType()`.

## Висновок
У лабораторній роботі було реалізовано наслідування класів `Shape`, `Circle` і `Rectangle`, використано `base`, `virtual`, `override` та `new`, а також показано поліморфізм і різницю між перевизначенням та приховуванням методів.
