# Самостійна робота №9 — звіт

## Чому делегати корисні?
Делегати дозволяють передавати в метод не тільки дані, а й поведінку. Завдяки цьому один generic-метод `Map`, `Filter`, `MaxBy` або `ForEach` працює з різними типами й умовами без дублювання коду.

## Як лямбда-вирази спрощують виклик?
Лямбда дозволяє коротко описати потрібну дію прямо в місці виклику, наприклад `n => n % 2 == 0` або `p => p.Price`. Не потрібно створювати окремий метод для кожної простої операції.

## Порівняння з LINQ
- `Map` відповідає `Select`.
- `Filter` відповідає `Where`.
- `MaxBy` близький до `Enumerable.MaxBy`.
- `ForEach` виконує дію для кожного елемента, тоді як стандартний LINQ орієнтований переважно на формування запитів.

Власна реалізація корисна для розуміння делегатів, generics та внутрішньої логіки LINQ, хоча у звичайному проєкті стандартний LINQ частіше зручніший.
