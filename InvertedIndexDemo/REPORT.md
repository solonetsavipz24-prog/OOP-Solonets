# Самостійна робота №10 — звіт

Реалізовано інвертований індекс `Dictionary<string, HashSet<int>>`: словник дає швидкий доступ до слова, а `HashSet<int>` зберігає унікальні ID документів. `SearchMultipleWords` використовує `IntersectWith`, а `SearchAnyWord` — `UnionWith`.

Для лінійного пошуку та індексу використовується однакова токенізація тексту. Це необхідно, щоб порівняння було коректним.

Програма автоматично проводить вимірювання для 10, 100, 1000 та 10000 документів і створює `RESULTS.md` у каталозі виконуваного файла. Після запуску скопіюйте цей файл до папки проєкту перед комітом.

Очікувано на малих наборах різниця може бути невеликою через накладні витрати, а на більших наборах повторний пошук через вже побудований індекс стає вигіднішим.
